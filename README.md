# SQL-курс на PostgreSQL

**Открыть онлайн:** https://stoyanovk.github.io/sql-course/

Практический курс SQL для backend-разработки. Настоящий Postgres прямо в браузере
(PGlite/WASM), авто-проверка каждого запроса. Цель — уверенно писать и читать
сложные Postgres-запросы.

## Запуск

**Просто открой курс онлайн:** https://stoyanovk.github.io/sql-course/

Курс задеплоен на **GitHub Pages** — ничего запускать локально не нужно. Правишь уроки →
пушишь в репозиторий → Pages обновляются. Нужен только **интернет** (движок Postgres/PGlite
подгружается с CDN при первом заходе).

### Локальный запуск (необязательно)

Дев-сервер больше не нужен для обычной работы, но остался как фолбэк для оффлайна/разработки.
Из папки `sql/`:

```bash
python3 serve.py        # http://localhost:8000/ , Ctrl+C для остановки
python3 serve.py 8080   # другой порт, если 8000 занят
```

На macOS можно дважды кликнуть `serve.command`. Зачем вообще сервер: уроки грузят ES-модули и
WASM, а при открытии файла двойным кликом (`file://`) браузер это блокирует. GitHub Pages (или
локальный `http.server`) отдаёт всё по http и снимает проблему.

## Структура

```
sql/
├── serve.py          # запуск локального сервера (python3 serve.py)
├── serve.command     # то же, но двойным кликом (macOS)
├── index.html        # стартовая страница курса
├── lessons/          # уроки (HTML)
├── reference/        # схема БД, глоссарий, программа курса
├── assets/           # engine.js (движок), seed.js (учебная БД), course.css
├── learning-records/ # что уже пройдено (для преподавателя)
├── MISSION.md        # цель курса
├── RESOURCES.md      # проверенные источники и сообщества
└── NOTES.md          # заметки по обучению
```

## С чего начать

1. Открой https://stoyanovk.github.io/sql-course/ (или локально `python3 serve.py`).
2. Пройди **Урок 0 — диагностику** (8 задач). ✅ Пройдена: 7/8.
3. Дальше — по калибровке: **Тема 04 — Агрегация (GROUP BY / HAVING)**, затем **Тема 05 — JOIN вглубь** (беглость).
