Запусти запрос ниже как есть. Потом поменяй customers на products или orders и запусти снова — просто чтобы почувствовать данные.

§2 Диагностика · 8 задач

решено 0 / 8

Задачи идут по нарастанию сложности. Решай, пока можешь. Где застрянешь — это и есть твоя граница, с неё начнём. Проверка автоматическая (✓ верно / ✗ пока нет). Решения здесь намеренно скрыты — они появятся в самих уроках.

Важно

После диагностики напиши мне в чат, до какой задачи дошёл и где споткнулся. Авто-проверка видит ✓/✗, но не видит тебя — по твоему ответу я построю следующий урок точно по размеру (не легко и не невыносимо).

1. Выведи все столбцы и все строки таблицы customers.

2. Выведи name и price товаров дороже 50.

3. Три самых дорогих товара: name и price, по убыванию цены. (важен порядок)

4. Для каждого заказа выведи order_id и имя покупателя (name). Должно получиться 14 строк.

5. Сколько заказов в каждом статусе? Выведи status и количество заказов.

6. Выручка по категориям. Для каждой категории, где были продажи, выведи имя категории (name) и суммарную выручку — сумму quantity * unit_price по всем проданным товарам этой категории.

7. Найди покупателей без единого заказа. Выведи их name.

8. Для каждого товара выведи name, category_id, price и его номер по дороговизне внутри своей категории (1 = самый дорогой). Столбец с номером назови rnk.
