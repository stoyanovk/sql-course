Как открывать

Курс живёт онлайн на GitHub Pages — просто открывай ссылки, ничего запускать не надо. Настоящий Postgres грузится прямо в браузере.

Нужен интернет: движок Postgres (PGlite) подгружается с CDN при первом заходе. Локальный запуск (необязательно, для оффлайна): из папки sql/ — python3 serve.py.
