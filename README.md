# SQL-курс на PostgreSQL

**Открыть онлайн:** https://stoyanovk.github.io/sql-course/

Практический курс SQL для backend-разработки. Настоящий Postgres прямо в браузере
(PGlite/WASM), авто-проверка каждого запроса. Цель — уверенно писать и читать
сложные Postgres-запросы.

## Запуск

Из этой папки (`sql/`):

```bash
python3 serve.py
```

Скрипт поднимет локальный сервер и **сам откроет браузер** на стартовой странице
(`http://localhost:8000/`). Остановить — `Ctrl+C` (или закрой окно терминала).

Другой порт, если 8000 занят:

```bash
python3 serve.py 8080
```

На macOS можно вместо команды **дважды кликнуть `serve.command`** — он делает то же самое.

### Зачем нужен сервер

Уроки грузят ES-модули и WASM (движок Postgres). При открытии HTML двойным кликом
(`file://`) браузер это блокирует. Локальный сервер решает проблему. Отдельного «кода
сервера» нет — `serve.py` использует модуль `http.server`, встроенный в Python.

### Требования

- **Python 3** (проверь: `python3 --version`).
- **Интернет** при первом запуске — движок Postgres (PGlite) подгружается с CDN.

## Структура

```
sql/
├── serve.py          # запуск локального сервера (python3 serve.py)
├── serve.command     # то же, но двойным кликом (macOS)
├── index.html        # стартовая страница курса
├── lessons/          # уроки (HTML)
├── reference/        # схема БД, глоссарий, программа курса
├── assets/           # engine.js (движок), seed.js (учебная БД), course.css
├── learning-records/ # что уже пройдено (для преподавателя)
├── MISSION.md        # цель курса
├── RESOURCES.md      # проверенные источники и сообщества
└── NOTES.md          # заметки по обучению
```

## С чего начать

1. Запусти `python3 serve.py`.
2. Пройди **Урок 0 — диагностику** (8 задач).
3. Дальше — **Тема 01: SELECT вглубь** и остальная программа (см. `reference/syllabus.html`).
