# NOTES — teaching preferences & working notes

## Learner (from claude-course-exersise/CLAUDE.md)
- Фулстек, 90% фронтенд: TypeScript, React, GraphQL, Apollo, SSR.
- Backend — учит: Node, Express, NestJS, **Postgres**, Redis, Python, aiohttp, SQLAlchemy.
- Хочет **короткие ответы, простые предложения**.
- Английский слабый → курс ведём **по-русски**; технические ключевые слова SQL оставляем как есть (SELECT, JOIN…).
- Для backend-кода любит объяснение решений («хочу учить backend»), не только ответ.

## How to teach here
- Одна идея на урок + сразу практика. Держись в рабочей памяти.
- Каждая тема ≥ 10 упражнений (запрос ученика).
- Практика — только в браузере (PGlite), с автопроверкой. Тесная петля.
- Каждый урок: короткое знание → эталонный источник (ссылка) → упражнения → «спроси учителя».
- Сложность в объяснениях — минимум; сложность в упражнениях — намеренная (retrieval, spacing, interleaving).
- Отвечать на вопросы ученика по SQL прямо в чате — я его учитель.

## ВАЖНО: кодировка
- Каждый HTML-файл ДОЛЖЕН начинаться с `<meta charset="utf-8">` (первой строкой, до <title>).
  Python http.server отдаёт `text/html` без charset → без meta браузер декодирует кириллицу как CP1251
  (mojibake вида «РљСѓСЂСЃ»). Meta-тег чинит это и на http, и на file://. Не забывать в новых уроках.

## Practice environment
- Курс отдаётся через локальный сервер `python3 serve.py` (или двойной клик `serve.command`),
  потому что file:// блокирует ES-модули/WASM. Порт по умолчанию 8000. serve.py ещё и шлёт charset=utf-8.
- Движок: PGlite (настоящий Postgres в WASM), грузится с jsDelivr CDN → нужен интернет.
  Если CDN однажды сломает API — запинить версию в `assets/engine.js` (PGLITE_URL).
- Данные: маленький интернет-магазин, см. `reference/schema.html`. НЕ менять схему без обновления упражнений.
